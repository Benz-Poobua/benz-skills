# benz-skills — PATHS (index of skills, agents and tools)

> Plugin `benz`. Call a skill with `/benz:<name>` (or let its description trigger it); spawn an agent with
> subagent type `benz:<agent>`. Rules for editing: `CLAUDE.md`.

## Core — every session

| skill | use when | extras |
|---|---|---|
| `core-evidence` | reporting any result, number, fix, citation or "done" | MEASURED / DERIVED / CITED / PREDICTED / RECORDED / UNVERIFIED labels; ran/skipped/not-verified block |
| `core-delegate` | before spawning subagents; broad reading; parallel menial work | `references/spec_template.md`; model tiers; concurrency <= 3 |
| `core-ledger` | starting cold; end of a work block; splitting a CLAUDE.md | `references/{CLAUDE,TASKS}_template.md`, `ledger_entry.md`; `scripts/check_doc_paths.py` |
| `core-long-run` | any job > ~10 min; account switches; worker counts | `templates/run_offline.sh`; `tools/guard.py` (thermal/battery pause, from mfold) |

## Code — research software

| skill | use when | extras |
|---|---|---|
| `code-house-style` | new repo/module, plots, configs, CLIs | `references/{module_header.py, plots_rcparams.py, utils_config.py}` (das_ani verbatim helpers) |
| `code-verify` | kernel/operator/adjoint/refactor changes; new numbers | gate table: analytic, dot-product, FD, drift, bitwise, no-op, one-ULP control, 5th-pct cosine |
| `code-fast` | optimizing, porting to Rust/CUDA, speed or memory claims | profile -> equivalence ladder -> equal-accuracy benchmark |
| `code-debug` | broken / wrong / slow / hanging | tight red loop, minimise, ranked hypotheses, regression test |
| `code-review` | review a diff, module or claim | blind pass, premise, trace seams, verdict |
| `code-notebooks` | any notebook | generated by `scripts/build_*_nb.py`; print + assert; gates JSON |
| `code-extract` | copying/porting external code | licence table; provenance header; drift gate; CITATIONS.md |
| `code-hpc` | SLURM / Sherlock | das_ani `submit.sh` pattern; TF32 off; sync/fetch rules |

## Paper — manuscripts and books

| skill | use when | extras |
|---|---|---|
| `paper-read` | reading a PDF to cite or extract | page offset, page/eq numbers, rendered-page sign checks; `references/note_template.md` |
| `paper-bib` | adding papers/bib entries; RIS imports; moving PDFs | `scripts/ris2bib.py`, `scripts/find_dup_pdfs.py`; `Lastname_etal_YYYY` convention |
| `paper-write` | any manuscript/book text | book first (published only); derive step by step; scope beside headline |
| `paper-numbers` | quoting numbers; before compiling | tracer pattern (`check_numbers.py`, fill scripts) |
| `paper-figures` | figures, `\smartfig` | one generator per figure; captions that reproduce |
| `paper-adopt` | adopting a published method into a repo | five questions + report block |

## Agents (model-tiered)

| agent | model | role | writes |
|---|---|---|---|
| `surveyor` | haiku | inventories, counts, licence IDs, tables from given facts | nothing (or one output file if the spec allows) |
| `reader` | sonnet | line-by-line reading notes with page/eq or file:line | the note file |
| `builder` | sonnet | one bounded change from a spec, with its gate | files the spec names |
| `verifier` | opus | independent re-check of claims, diffs, numbers, citations | nothing (or one report file) |

## Related, outside this plugin

- Repo-specific skills: `<repo>/skills/<name>/SKILL.md` (listed in each repo's CLAUDE.md header).
- Book skills: `../mypaper/mybible/skills/{book-verify,book-figures,book-ledger}`.
- Companion plugin: `caveman` (terse chat, default on).
